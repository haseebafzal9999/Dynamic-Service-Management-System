# 🚀 Dynamic Service Management System

> A Professional ASP.NET MVC Enterprise Workflow & Service Automation Platform

---

# 📌 Project Overview

The **Dynamic Service Management System** is a service-based enterprise application developed using **ASP.NET MVC** and **SQL Server**.

This system is designed to manage:

- ✅ Dynamic Templates
- ✅ Configurable Questionnaires
- ✅ Dependency-Based Questions
- ✅ Material & Component Management
- ✅ Workflow Automation
- ✅ User Response Tracking
- ✅ Template Versioning

The project follows a scalable and modular enterprise architecture suitable for dynamic workflow systems.

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/haseebafzal9999/Dynamic-Service-Management-System.git
```

---

## 2️⃣ Open Project

Open solution using:

- Visual Studio

---

## 3️⃣ Configure Database

### Option 1 — Restore Backup
Restore database using SQL Server Management Studio from:

```bash
DB Backups/
```

### Option 2 — Run SQL Scripts
Execute SQL scripts manually in SQL Server.

---

## 4️⃣ Configure Connection String

Update the connection string inside:

```bash
Web.config
```

---

## 5️⃣ Run Application

Press:

```bash
F5
```

OR

```bash
Ctrl + F5
```
